Адаптировать для своей версии ядра (Структура обработчиков): в коде procmod.c написана структура proc_ops, для адаптации под мою версию ядра.

Избавиться от харкода (маг чисел): в коде procmod.c вместо числа 10 использован макрос #define BUF_SIZE 100.

Изолировать переменные модуля (static): в коде procmod.c все глобальные переменные (msg, len, temp) объявлены с ключевым словом static, для того, чтобы они были видны только внутри моего модуля.
