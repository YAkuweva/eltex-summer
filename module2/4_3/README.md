4.3. Доработать решение задачи 2.1 так, чтобы для хранения данных использовалось бинарное дерево. Добавить периодическую балансировку дерева.


Реализация:

Вместо массива теперь используется бинарное дерево поиска. В структуру Contact добавлены указатели: *left, *right. Контакты хранятся в узлах дерева, память выделяется динамически через malloc().
Сортировка в дереве: контакты упорядочены по фамилии, затем по имени. При добавлении новый узел сравнивается с существующими и вставляется в левое или правое поддерево. Периодическая балансировка: после каждых 10 добавлений или удалений вызывается балансировка. Все узлы собираются в отсортированный массив. Из массива строится сбалансированное дерево (берётся средний элемент как корень).


Тесты:

1) Добавление одного контакта.

2) Добавление 15 контактов.

3) Удаление контакта.

4) Балансировка дерева.

5) Периодическая балансировка после 10 операций.
