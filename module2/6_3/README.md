6.3. Доработать решение задачи 2.3 так, чтобы функции загружались из динамических библиотек. 
В одной библиотеке находится одна функция. При запуске программы считывается каталог с
библиотеками и загружаются найденные функции.


Реализация:
Каждая операция (+, -, /, *, ^) вынесена в отдельный .c файл Из каждого файла собирается отдельная динамическая библиотека .so
В одной библиотеке — одна функция

Программа сканирует папку plugins/ при запуске. Находит все файлы с расширением .so
Загружает каждую библиотеку с помощью dlopen(). Получает адрес функции через dlsym().
Сохраняет указатели на функции в массив структур Command

Меню: программа определяет доступные операции при запуске. Имена команд извлекаются из имён файлов (libadd.so → add → "Add").
Меню строится динамически на основе загруженных плагинов.

Используемые функции:
dlopen() — загрузка библиотеки
dlsym() — получение адреса функции
dlclose() — выгрузка библиотеки
dlerror() — обработка ошибок
